# Bolt instructions for Claude-based workflows

Read and follow the repository's `AGENTS.md` and `docs/agent-workflow.md`. They are the shared project guidance for people and agents across workstations. Read any applicable nested instructions and the approved feature plan before implementation.

Use Claude-specific tooling when available without creating a conflicting project process. Do not impose model names, editor commands, a particular cloud filesystem or approval on every multi-file edit. The approved task scope governs routine work; escalate material changes and unresolved requirements.

For personal daily logs, retain the existing opt-in convention: write only when requested, keep them local under `daily-logs/`, and exclude that directory through local Git exclusions. Never commit or push personal logs.

Keep communication direct and evidence-based. Avoid filler and emojis. Shared branch, deployment, data and review boundaries are in `AGENTS.md`; maintain them there rather than duplicating divergent rules here.
